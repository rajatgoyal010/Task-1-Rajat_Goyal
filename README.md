# Advanced To-Do List Manager

A feature-rich **Python-based To-Do List application** designed to help users organize and manage their daily tasks efficiently. The project provides an intuitive GUI built with **Tkinter** and stores data locally using **JSON**, making it lightweight and easy to use.

## Features

-  Add new tasks
-  Edit existing tasks
-  Mark tasks as completed
-  Delete tasks
-  Set task priorities (High, Medium, Low)
-  Organize tasks by category
-  Add due dates
-  Automatic data saving using JSON
-  Search and filter tasks
-  Track completed and pending tasks
-  User-friendly graphical interface

##  Technologies Used

- Python 3
- Tkinter
- JSON
- Object-Oriented Programming (OOP)

```bash

```

### 2. Navigate to the project folder

```bash
cd advanced-todo-list
```

### 3. Run the application

```bash
python main.py
```
